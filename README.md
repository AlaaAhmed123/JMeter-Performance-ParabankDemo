# JMeter Performance – Parabank Demo

## 📌 Project Overview
This project contains performance test scripts for the Parabank demo application using Apache JMeter.

The goal is to simulate user load, measure response times, and analyze system behavior under stress.

---

## 🛠 Tools & Technologies
- Apache JMeter 5.6.3
- CSV Data Set Config
- Regular Expression Extractor (Correlation)
- JMeter Functions
- HTML Dashboard Report
